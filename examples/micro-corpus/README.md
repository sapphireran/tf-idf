# Micro corpus

Three one-line documents used in
[docs/worked-example.md](../../docs/worked-example.md).

| File | Text |
| --- | --- |
| `d1-cat.txt` | the cat sat on the mat |
| `d2-dog.txt` | the dog sat on the log |
| `d3-bread.txt` | bakers bake bread |

`N = 3`. Every token is already lowercase ASCII with no punctuation,
so the tokenizer is a no-op besides splitting on spaces.

Do not add a fourth file here: the worked-example page lists every
IDF value for this exact collection.
